# Odoo IoT HeartBeat Module 💓🤖

![Odoo Version](https://img.shields.io/badge/Odoo-14.0%2B-purple.svg)
![License](https://img.shields.io/badge/License-LGPL--3-blue.svg)
![IoT](https://img.shields.io/badge/IoT-Integration-orange.svg)

An Odoo module designed to monitor, track, and maintain real-time status (heartbeat) updates for connected IoT (Internet of Things) devices and Box integrations.

---

## 📌 Features

- 🔄 **Real-Time Heartbeat Monitoring**: Track active status and ping connection intervals of connected IoT devices.
- ⚠️ **Automated Offline Alerts**: Detect disconnected or non-responsive devices automatically.
- 📊 **Status Dashboard / Logs**: Detailed logs and history of heartbeat signals sent from IoT devices.
- ⚙️ **Easy Configuration**: Simple setup for heartbeat interval timeouts and alert notifications.
